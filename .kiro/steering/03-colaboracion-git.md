# Colaboración, Git y repositorios

- Trabajar con ramas y cambios pequeños, enfocados y revisables; no incluir secretos, datos sensibles, artefactos pesados ni resultados no reproducibles.
- Describir en cada cambio el propósito, fuentes, transformaciones, validaciones, impacto y pasos para reproducirlo. Mantener README, diccionario y changelog actualizados.
- Antes de integrar, ejecutar validaciones disponibles, revisar diferencias, consultas, medidas y documentación; solicitar revisión por pares para cambios analíticos relevantes.
- Resolver conflictos preservando definiciones y trazabilidad; no sobrescribir trabajo ajeno ni cambiar una métrica sin registrar la decisión y su impacto.
- Usar nombres consistentes, parámetros explícitos y configuración separada de credenciales. Reportar limitaciones o validaciones pendientes.
